# Lodgia — Hotel Booking Platform
React + TypeScript + Vite · React Router v6 · Redux Toolkit · Formik + Yup

    npm install
    npm run dev

Routes: `/`, `/bookings`, `/bookings/:bookingId` (useParams)
State: `src/bookingsSlice.ts` (addBooking / updateBooking / removeBooking)
Form: `src/components/BookingForm.tsx` (useFormik + Yup)
